🍳 なぜ Kitchen が最適なのか

  • 🧡 オレンジ = 世界中の飲食ブランド定番（マクドナルド・ミスド・Dunkin'）
  • 🌿 ライム緑のアクセント = 新鮮な野菜・ハーブを連想
  • 🍞 クリーム背景 = ベーカリー・カフェの温かい雰囲気
  • 📖 丸ボタン・丸ロゴ = 親しみやすく、堅くない
  • 🇯🇵 Zen Kaku Gothic = 日本語が美しく柔らかい
  • ✨ 食材・料理の写真を載せた時に 色が喧嘩しない
印象温かい・親しみ・美味しそう
対応業態カフェ / 定食屋 / ベーカリー / 喫茶店 / 洋食店 / ファミレス / 居酒屋 / ラーメン店
特徴レシピ写真を邪魔しない背景色。丸みを多用した柔らかいUI。誰でも触れる親しみ感
